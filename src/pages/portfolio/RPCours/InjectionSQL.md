## Contexte

Dans le cadre de mon **_BTS SIO_** au Campus La Châtaigneraie, j'ai étudié les injections SQL comme risque majeur pour les applications connectées à une base de données. J'ai appris à reconnaître les points vulnérables dans les formulaires et les requêtes, puis à mettre en place de bonnes pratiques de protection. Ce travail m'a permis de mieux lier sécurité applicative et développement web.

## Environnement technologique

Pour cette réalisation, j'ai utilisé Visual Studio Code, PHP, PDO et MySQL via WAMP pour créer des exemples vulnérables puis les corriger. J'ai comparé des requêtes non sécurisées avec des requêtes préparées afin d'observer concrètement la différence de comportement. Cette démarche m'a aidé à comprendre comment sécuriser les accès aux données en pratique.
